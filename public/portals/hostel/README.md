# HostelFlow — School Hostel Management System

Complete mobile-responsive hostel management system for schools.

## Modules

| Module | Features |
|--------|----------|
| **Dashboard** | KPIs, occupancy, tonight's attendance, quick actions |
| **Boarders** | Student directory, room/bed, parent contacts, fee status |
| **Rooms & Allocation** | Capacity, occupancy progress, vacant beds |
| **Night Attendance** | Mark Present / Absent / Leave with timestamps |
| **Mess Management** | Daily menu (B/L/S/D) + feedback ratings |
| **Hostel Fees** | Monthly fee, due amounts, collect payments |
| **Leave / Outing** | Approve / reject student leave requests |
| **Visitors Log** | Entry-exit tracking, check-out |
| **Complaints** | Maintenance, cleanliness, priority & resolve |
| **Staff / Wardens** | Warden & staff directory |
| **Reports** | 8 report types ready to generate |

## How to Run
1. Open `index.html` in any modern browser
2. Fully mobile responsive (hamburger menu on phones)
3. No installation needed

**Demo Hostel:** Boys Hostel A • St. Xavier's High School, Sambalpur
