# TeachFlow — Teacher Portal

A complete, mobile-responsive **Teacher Portal** for school teachers.

## Features

| Module | Description |
|--------|-------------|
| **Dashboard** | Upcoming classes, quick stats, today's schedule, quick actions |
| **My Classes** | Class & section management with attendance & score averages |
| **Timetable** | Full weekly timetable with day tabs |
| **Attendance** | Mark P/A/L per student • Biometric sync ready |
| **Homework** | Upload & track submissions with progress bars |
| **Marks Entry** | Online marks entry with live score sheet |
| **Exam Management** | Schedule exams, view status & results |
| **Performance** | Class average trends + top performers + needs attention |
| **Leave Application** | Apply leave + history + balance |

## How to Run
1. Open `index.html` in any modern browser
2. Fully mobile responsive (hamburger menu on phones)
3. No server required
